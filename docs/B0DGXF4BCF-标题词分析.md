## 你最初的设想（要恢复的工作方式）

不是先写标题，再找句子来撑。顺序只能是：

1. **先找原话**：标题 + 正文里，完整单词、不去同义合并，出现 ≥2 次的短语分别列清；4–5 星抽收益，1–3 星抽顾虑。
2. **再看洞察**：同一短语在上下文里到底在说什么；同句不同义要拆开，不能加总。
3. **最后选词**：能进标题的必须同时满足——买家真的这么说或这么搜、产品能兑现、比空泛好评更具体。

两份文件分工也要分开，不能混成一种证据：

| 文件 | 解决什么 | 不解决什么 |
| --- | --- | --- |
| 搜索词 CSV | 产品词、需求词（标题主干从这里来） | 不能当评论，不能证明买家夸什么、怕什么 |
| 评论 xlsx | 收益表达、顾虑表达（标题利益点从这里来） | 单次生动金句不能冒充重复原话 |

输出格式也要固定成四列，而不是先给两个标题草案：

**德语原句 → 出现条数 → 买家洞察 → 标题候选表达（或不进标题）**

图里「同一句话出现两次就放进标题」只是发现漏斗，不是入选开关。还要看：是不是独立买家、是不是核心需求、产品能不能兑现、以及它该进标题还是进五点。

### 5. 把不该进标题决策表的词，和产品效用词放在一起

`sehr gut`、`schnelle Lieferung`、`sehr zufrieden`、`wie beschrieben` 出现次数高，但对写标题几乎没有用。它们会把真正该比的词（`einfach anzubringen`、`Knöpfe halten`、`Beschreibung fehlt`）挤乱。

`den Dreh` 是「掌握诀窍」的残片，不能当标题词。

法语 `Facile d'utilisation` 可以帮你理解需求，不能冒充德语重复原话。

### 6. 选词只写到第 1 名就断了

最后停在 `einfach anzubringen`。按你的方法，这一步必须排完、必须标明「进标题 / 进五点 / 不写」。只给一个词，等于方法没有走完。

更关键的是：把 `einfach anzubringen` 排第一，是因为它「比很好用具体」，不是因为它在重复原话里证据最强。证据最强的结果原话是 `Knöpfe halten`（5 次）。选词要同时看**重复次数、具体程度、正负是否打架、搜索词是否接力**，不能只看「像不像标题」。

### 7. 搜索词和评论没有按你的方法合流

你最初是：搜索词定主干和需求词，评论补收益和顾虑。

最后一版为了严格执行「只看 ≥2 原话」，把搜索量最高、产品也支持的 `ohne Nähen` 从选词里拿掉了。这不是更严谨，是把两个证据源收成了一个。

### 2. 从这些重复原话看出的洞察

只从第 1 步的短语和它们的上下文推，不把单次金句写进证据列。

| 重复原话（及上下文） | 支持的洞察 | 不能直接推出什么 |
| --- | --- | --- |
| einfach anzubringen、leicht zu bedienen、einfache Handhabung | 买家反复认可的是「装上去不难」，不是「东西看起来高级」 | 不能说新手都能一次成功 |
| Beschreibung fehlt、eine Beschreibung、wäre hilfreich、zu kompliziert、den Dreh、das Video | 真正的门槛在第一次搞懂零件怎么配、胶头怎么换；懂了以后不少人会改口说简单 | 不能把所有失败都归咎于没说明书；也不能把「缺说明」写成已经随附 |
| Knöpfe halten、Knöpfe halten super、halten gut | 装好以后扣子还在布上，是明确满意点 | 不能保证永不脱落、长期耐洗。Amazon 页面「耐用性」正负约各半，和这组好评是并立的 |

| Preis Leistung、erfüllt seinen Zweck | 有人认可它以较低成本把事做完 | 不能因此写成专业级、高强度工具 |
| tolles Set + 颜色/配对比（主题，非本表加总） | 买家关心的是能配成多少套完整按扣、要的颜色够不够 | 不能只靠「250」这个大数字；要能对上完整套数 |

一句话收束：**买家要的是装的时候不折腾，装好以后能固定住。**

场景洞察仍然成立，但证据级别不同：修被套、不用重缝拉链，是有价值的购买理由，只是原句没有 ≥2 次，所以它属于洞察层，不属于第 1 步证据表，默认不进标题。

- `druckknopf set mit zange`：产品主干，评论里 `Druckknopf Set`、`mit Zange` 也能对上。
- `ohne nähen`：需求词，listing 支持免缝；评论里有相近表达，但不是 ≥2 次同一原句。
- `für stoff` / `jersey` / `dicke stoffe` / `bettwäsche`：面料和场景筛选词。厚布评价打架，不能写成通用；床品是后续可测场景，不是当前重复原话。

## 当买家用不同词说同一件事：怎么发现、提取、写进文案

「同一原句 ≥2 次」只能保住买家语言，保不住分散表达的需求。说明书就是这种情况：没有一句占绝对多数，但很多人在说同一件事。

正确做法是加一层，**不要和原句层混成一张表、一个数字**。

### 先分清两层各干什么

| 层 | 数什么 | 发现什么 | 不能干什么 |
| --- | --- | --- | --- |
| 原句层 | 完全相同的连续词，≥2 次 | 可直接考虑进标题的买家措辞 | 不能因为意思像就合并 |
| 意思簇 | 独立评论人数（一条评论只计 1） | 这件事够不够重要、文案要不要回应 | 不能把簇名当成买家原话，也不能把簇人数写成「N 人说了同一句」 |

原句层回答：他们**怎么说**。  
意思簇回答：这件事**重不重**。  
文案用词优先来自原句层；进不进页面、写多具体，看意思簇。

### 怎么发现一个簇（不必事先知道「说明书很重要」）

触发条件，满足一条就开簇，不要给所有评论强行归类：

1. **几个不同的 ≥2 原句，共用同一批内容词。**  
   这里已经出现：`keine Anleitung`、`eine Beschreibung`、`Beschreibung fehlt`、`eine Bedienungsanleitung`。词不一样，都在说「说明」。
2. **高星和低星都在提同一摩擦。**  
   缺说明在 4–5 星里也有。说明它不是差评专属攻击，是上手门槛。
3. **有人写「看了视频才会」或「掌握诀窍后才简单」。**  
   这是同一簇的变体：问题不在每次使用，而在第一次没人告诉怎么配。

不要靠同义词表把 `einfach anzubringen` 和 `keine Anleitung` 并成一簇。前者是装上之后觉得容易，后者是装之前没人教。

### 开簇之后怎么提取（种子召回，不是脑补合并）

对「说明书 / 第一次不会」这一簇，按这个顺序做：

**第 1 步：从原句层抄种子词。**  
只抄名词和关键动词，不抄 `keine`、`eine` 这种语法词：

`Anleitung` / `Beschreibung` / `Bedienungsanleitung` / `Gebrauchsanweisung` / `Video` / `Bild`

**第 2 步：用种子回搜全部评论（含只出现 1 次的）。**  
Excel 里对标题+正文筛选即可。这会捞到原句层漏掉的：

- `Eine deutsche Anleitung`
- `mit Bild wäre gut`
- `Gebrauchsanweisung fehlt`
- `keinerlei Info oder Anleitung`

**第 3 步：再读一遍召回结果的前后句，补「没用这些词、但在说同一件事」的。**  
例如：`welcher Stöpsel zu welchem Teil gehört`、`zu kompliziert`、`den Dreh`、`bei der ersten Benutzung`。  
这一步必须人工看上下文，机器按词搜会漏。

**第 4 步：填簇卡片，人数和原句分开记。**

| 字段 | 这一簇怎么填 |
| --- | --- |
| 簇名（内部用，不进标题） | 第一次安装时缺说明 |
| 独立评论人数 | 上一轮约 21 条（13 条 4–5 星，8 条 1–3 星）；Amazon 页面「缺说明」约 11 人、9 负 2 正。两套口径不要加总 |
| 极性 | 要拆开：多数是「缺 / 希望有」；`keine Anleitung`、`eine Bedienungsanleitung` 里各有「不需要说明书」的反例，反例不算进「缺说明人数」 |
| 簇内原句（可复用的词） | Anleitung、Beschreibung、Bedienungsanleitung |
| 只出现 1 次、让解决方案更具体的修饰 | Bild（要图）、deutsche（要德语）、welcher Stöpsel（要讲清胶头对应） |
| 买家真正要完成的事 | 第一次就知道哪个零件放哪边，不用猜、不必先去翻卖家视频 |

**第 5 步：簇内再切开，不要写成一个笼统的「要说明书」。**  
否则文案只能写出空洞的 `mit Anleitung`，而买家卡的其实不是有没有一张纸。

| 子需求 | 证据强度 | 对文案的含义 |
| --- | --- | --- |
| 包装里要有说明 | 原句层已重复：Anleitung / Beschreibung / fehlt | 核心：页面必须回应「有说明」 |
| 最好有图 | 1 次 `mit Bild wäre gut` | 有图解才写 bebildert；没有就不要写 |
| 要德语 | 1 次 `Eine deutsche Anleitung` | 德语版才写 deutsch；英文纸说明回应不了这条 |
| 讲清胶头对应哪个零件 | 1 次，但是把障碍说死了 | 不进标题；必须进说明书/主图/视频画面 |
| 看视频才会 | `das Video` 2 次 | 有视频可写 `inkl. Video-Anleitung`（须真实）；不能代替包装说明 |

### 簇里的词怎么用到文案

判断口诀：

1. **簇人数决定要不要回应** —— 这一簇够大，值得进标题测试、五点或主图，不能因为没有一句 ≥10 次就丢掉。
2. **原句层决定用哪个词** —— 可复用的德语词是 `Anleitung`、`Beschreibung`，不是 `说明书很重要` 这句中文。
3. **抱怨句不能原样进标题** —— `keine Anleitung`、`Beschreibung fehlt` 是问题，不是卖点。标题只写产品已经提供的对应物。
4. **1 次出现的修饰词，只有产品真有、且能降低这个簇的主障碍时，才用来写具体。**  
   `Bild`、`deutsch` 次数少，但它们让「有说明」变得可验证。可以进五点；进标题前必须核对包装。
5. **写解决方案，并标明这是归纳文案。**

| 产品实际情况 | 可以用 | 不要写 | 放哪里 |
| --- | --- | --- | --- |
| 盒内德语图解，并讲清胶头对应 | `mit bebilderter Anleitung` 或更实的 `mit deutscher Anleitung` | `keine Anleitung`、`超简单不用看说明` | 标题可测；五点写清「图解说明胶头怎么换」 |
| 只有 listing 视频，盒内没有纸 | `Video-Anleitung auf der Produktseite` | 标题里的 `mit Anleitung`（买家拆盒会打脸） | 五点 + 主图口播/视频入口 |
| 什么说明都没有 | 先改包装/A+，再写文案 | 任何 Anleitung 承诺 | 不能靠改标题消掉这个簇 |

这一簇最值得留下的文案不是「操作简单」，而是：**第一次不用猜哪个配件放哪边。**

标题测试（仅当盒内真有图解）：

`Druckknopf Set mit Zange – ohne Nähen, mit bebilderter Anleitung`

五点用归纳，把 1 次出现但说得很死的障碍写进去：

`Mit bebilderter Anleitung: welcher Einsatz zu welchem Druckknopf gehört.`

这句不是买家原话重复 ≥2，而是用簇证明「值得写」、用那条单次原话证明「要写到多具体」。两层证据都要标注，不能写成「很多人都说了 mit bebilderter Anleitung」。

### 以后遇到类似情况（颜色不够、厚布装不上、零件配不齐）

都用同一张簇卡片，不要再把不同原句加总成一句假原话：

1. 原句层照常做，词不一样就分行。
2. 多个 ≥2 原句指向同一摩擦 → 开簇。
3. 种子回搜 + 人工补漏。
4. 数独立人数和极性；1 次修饰词单独一行。
5. 文案：抱怨变解决方案；原句给用词；簇给是否值得占标题位置。

## 以后按这张操作卡做，才算回到原设想

1. 搜索词表只出产品词 / 需求词，标来源为搜索。
2. 评论先去重，再切 4–5 星和 1–3 星。
3. 各桶里只提取 ≥2 次的完整原话；嵌套短语并排展示，次数不加成。
4. 极性相反的同一短语拆成两行。
5. 空泛好评和物流词进附录，不进选词表。
6. 若多个不同原句指向同一摩擦，另开意思簇：种子召回 → 独立人数 → 子需求；簇人数不要写进原句表。
7. 洞察只许从原句上下文或簇卡片出；单次金句可给簇「写到多具体」，不冒充重复原话。
8. 选词时：主干看搜索，收益看 4–5 星原话，顾虑簇只在产品已经改掉时才改写成标题差异化。
9. 输出必须有四列，且第 3 步（选词）要写完「进标题 / 进五点 / 不写」。
